CALISTHENICS RANK — app pessoal (PWA, offline, só no seu iPhone)
=================================================================

COMO COLOCAR NO AR (mesmo processo de antes)
1. Descompacte o .zip no computador (ou use o app Arquivos do iPhone).
2. Netlify Drop (app.netlify.com/drop): arraste a PASTA descompactada (com index.html dentro).
   Ou GitHub Pages: envie todos os arquivos para o repositório.
3. No iPhone, abra o link no Safari > Compartilhar > "Adicionar à Tela de Início".
   Abra uma vez com internet; depois funciona offline.

COMO ATUALIZAR (quando eu te mandar uma versão nova)
1. Suba os arquivos novos NO MESMO site (mesmo link). Seus dados continuam no aparelho.
2. Se você mesmo mexer em algum arquivo, aumente o número em sw.js:  const V = 'calisthenics-v6';
3. Abra o app com internet, feche e abra de novo.
   IMPORTANTE: se o link mudar, os dados NÃO vêm junto. Antes de trocar, use Profile > Backup > Export.

SEUS DADOS ANTIGOS: se você usava a versão em português NO MESMO link, refeições, água, peso e
dias treinados são importados automaticamente na primeira abertura.

COMO O RANK É CALCULADO (resumo; dentro do app: Ranks > ícone "i")
- Cada série vale 0–1000 pontos, conforme uma tabela por exercício/variação (ex.: 13 pull-ups ≈ 400 pts).
- A cada 100 pts = um tier: Iron, Bronze, Silver, Gold, Platinum, Diamond, Master, Elite, Legend (800+),
  cada um com degraus I, II, III (Legend não tem).
- Peso extra vira "repetições equivalentes" pela fórmula de Epley (1RM = carga × (1 + reps/30)).
- Rank do exercício = sua melhor série (sempre, ou nos últimos 30/90 dias — Profile).
- Rank do músculo = média ponderada das 3 melhores contribuições dos exercícios que o trabalham.
- Rank geral = média dos 13 músculos; libera com 3 exercícios ranqueados.
- Nível/XP (separado do rank): 50 XP por treino + 10 por série.
- As tabelas iniciais são estimativas baseadas em padrões públicos; edite em Ranks > Exercises > (exercício) > Edit scale.

FONTES (pesquisa)
- Strength Level: padrões de pull-ups, push-ups e dips
- FitnessVolt: progressões de front lever e planche
- BoxRox: referência de muscle-up
- Liftoff (liftoffrank.com): conceito de ranks por exercício/músculo
Obs.: amigos, ligas e ranking global exigem servidor — não existem neste app (tudo é só no seu aparelho).
